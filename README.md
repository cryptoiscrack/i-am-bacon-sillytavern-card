# I Am Bacon — SillyTavern Character Card

<img src="card.png" alt="I Am Bacon — character card" width="340">



I Am Bacon (@howdyiambacon, YouTube @HowdyIAmBacon), the South African YouTuber whose fascist.eth video has a Bitcoin Obama cameo, and who recorded a podcast with Bitcoin Obama on Oct 6, 2026.

**I Am Bacon** — official **SillyTavern character card** (Character Card V2, with the PNG card also embedding V3) for chatting with I Am Bacon in SillyTavern — it also imports into Chub AI, Janitor AI, Agnai, RisuAI and Backyard AI.

## Files

- `i-am-bacon.sillytavern.card.json` — the character card in JSON form.
- `card.png` — the PNG character card (same card, image form) where included.

## Use it

SillyTavern: Characters → Import Character → choose the card JSON or PNG.
